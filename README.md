# Showdown Coach 对战复盘演示

一页静态演示，展示一场 Pokémon Showdown Gen 9 OU 对局的逐回合复盘。使用播放、滑块、回合按钮或曲线数据点切换回合，右侧同步显示该回合的对战事件。

- [同一场对局的官方动画回放](https://replay.pokemonshowdown.com/gen9ou-2718283592)
- 曲线来自该局模型方的赛后分析，每个点对应该回合行动前的胜率估计。终局赛果单独显示。
- 演示数据包括公开回放的精选事件、双方已公开的场上宝可梦和这场对局的曲线。原项目的后端服务、模型和对局档案保留在独立工作区。

页面由 GitHub Pages 从 `main` 根目录提供。也可以在本地浏览器打开 `index.html`。
